# زاد العلم 🌿 — Rust + Tauri 2

> **رفيقك اليومي لتعلم وتأصيل العلوم الشرعية بالتكرار المتباعد (Anki-style) وبنك الأسئلة والاختبارات الفورية مع ودجت سطح المكتب العائم.**

---

## 📖 ما هو "زاد العلم"؟

**زاد العلم** هو تطبيق سطح مكتب إسلامي فائق الخفة والسرعة، مبني بالكامل بـ **Rust** و **Tauri 2** (نفس البنية التقنية لتطبيق **زاد المسلم**)، صُمم خصيصاً لطلاب العلم والمسلمين الراغبين في ضبط وتأصيل العلوم الشرعية بأسلوب علمي حديث وممتع.

يجمع التطبيق بين:
1. **منهجية التكرار المتباعد (Spaced Repetition - SM-2)** المشهورة في تطبيق Anki لترسيخ المتون والقواعد الفقهية والعقدية في الذاكرة طويلة المدى.
2. **بنك أسئلة واختبارات قياس الفهم التفاعلية** مع تصحيح فوري وكشف التأصيل والدليل الشرعي من القرآن والسنة وأقوال أئمة الإسلام فور الإجابة.
3. **ودجت عائم خفيف على سطح المكتب** (مثل ودجت زاد المسلم) يطفو أثناء استخدامك للكمبيوتر ليعرض عليك مسائل واستذكارات سريعة وتتفاعل معه بضغطة زر واحدة.
4. **أيقونة شريط المهام (System Tray)** مع عداد ذكي للبطاقات المستحقة لمراجعة اليوم.

---

## ✨ المميزات والخصائص الرئيسية

### 1. 🧠 محرك التكرار المتباعد الذكي (Anki SM-2)
- جدولة ذكية للمسائل وفق 4 مستويات تقييم:
  - 🔴 **أعد (Again)**: لإعادة المسألة التي غابت عن الذهن فوراً وتصفير فترتها.
  - 🟡 **صعب (Hard)**: إذا استحضرت المسألة بمشقة فيتم تقريب موعدها.
  - 🟢 **جيد (Good)**: الحفظ السليم المتقن مع زيادة الفترة.
  - 🔵 **سهل (Easy)**: الاستحضار الفوري المتقن مع مضاعفة الفترة.
- دعم كامل لاختصارات لوحة المفاتيح: المسافة (`Space`) لكشف الجواب، والأرقام (`1`، `2`، `3`، `4`) للتقييم الفوري السريع.

### 2. 🗂️ الدعم الكامل لرزم وقوالب أنكي (Anki Decks & Templates)
- **استيراد ملفات `.apkg` و `.colpkg` مباشرة**: عبر سحب وإفلات الملف أو زر الاستيراد، حيث يقوم البرنامج بفك ضغط الحزمة وقراءة قاعدة بيانات SQLite الداخلية واستخراج البطاقات والملاحظات تلقائياً.
- **دعم قوالب البطاقات (Note Types / Card Templates)**:
  - معالجة صيغ موستاش (Mustache syntax): `{{Field}}` و `{{FrontSide}}`.
  - معالجة الشروط: `{{#Field}}...{{/Field}}` و `{{^Field}}...{{/Field}}`.
  - تطبيق تنسيقات CSS الخاصة بكل قالب ونموذج بطاقة.
- **دعم ملء الفراغات وإخفاء الكلمات (Cloze Deletion)**:
  - دعم كامل لصيغ `{{c1::النص}}` و `{{c1::النص::تلميح}}`.
  - إخفاء الكلمة المستهدفة في شاشة السؤال وإظهارها بلون مميز في شاشة الإجابة.
  - مثالي ومخصص لطلاب العلم في **حفظ المتون الشرعية، والقرآن الكريم، والأحاديث النبوية** مقطعاً مقطعاً.
- **دعم الوسائط وملفات الصوت المرفقة**:
  - استخراج وسائط الرزم وتشغيلها فورياً عبر وسوم `[sound:filename.mp3]`.
- **عزل وتنظيم الرزم**:
  - إمكانية دراسة أو اختبار رزمة محددة منفصلة، أو دراسة جميع الرزم معاً.
  - يتضمن المشروع عينة رزمة حقيقية بصيغة أنكي: [`data/sample_hadith_cloze.apkg`](file:///teamspace/studios/this_studio/zad-ilm/data/sample_hadith_cloze.apkg).

### 3. ❓ بنك الأسئلة واختبارات قياس الفهم (Quiz Mode)
- أسئلة تفاعلية فورية في أبواب العلم الشرعي.
- تصحيح فوري عند الضغط: تلوين الإجابة الصحيحة بالأخضر والخطأ بالأحمر.
- كشف صندوق **التأصيل والدليل الشرعي** فوراً: يشرح وجه الحكم الشرعي، الدليل من الآية أو الحديث الشريف، وأقوال أئمة المذاهب.
- متابعة نسبة الدقة ومجموع الإجابات الصحيحة وعداد الأيام المتتالية (Streak 🔥).

### 4. ⚡ ودجت سطح المكتب العائم (Desktop Widget)
- نافذة عائمة شبه شفافة ذات تصميم زجاجي فاخر بحواف منحنية.
- تبقى دائماً في المقدمة أثناء تصفحك أو عملك على الكمبيوتر (Always on Top).
- إمكانية التفاعل الكامل مع المسألة أو الكويز أو بطاقات Cloze من داخل الودجت نفسه، أو التوسيع للنافذة الرئيسية.
- جدولة دورية قابلة للتخصيص (مثلاً ظهور الودجت كل 30 دقيقة بمسألة جديدة).

### 5. 📚 رصيد غني من العلوم الشرعية المعتمدة
يتضمن البرنامج رصيداً تأسيسياً مرتباً وموثقاً في:
- **العقيدة والتوحيد**: (الأصول الثلاثة، أقسام التوحيد، شروط لا إله إلا الله، نواقض الإسلام، القواعد الأربع، أركان الإيمان، الأسماء والصفات).
- **فقه العبادات**: (الطهارة والوضوء، المسح على الخفين، الصلاة وشروطها وأركانها وواجباتها، سجود السهو، الصيام ومفسداته، الزكاة والأنصبة، الحج وأركانه).
- **القواعد الفقهية الكبرى**: (الأمور بمقاصدها، اليقين لا يزول بالشك، المشقة تجلب التيسير، الضرر يزال، العادة محكمة).
- **الحديث ومصطلحه**: (الأربعين النووية، أقسام الحديث: الصحيح، الحسن، الضعيف، المتواتر، الآحاد، المرسل، المنقطع).
- **علوم القرآن والتفسير**: (المكي والمدني، أسباب النزول، قواعد التفسير، غريب كلمات قصار السور).
- **السيرة النبوية والآداب**: (أحداث السيرة الكبرى، غزوة بدر، حلية طالب العلم، آداب الطلب).
- **أصول الفقه**: (الأحكام التكليفية الخمسة، أدلة الأحكام، القياس وأركانه).
- **اللغة العربية والنحو**: (أقسام الكلام، علامات الإعراب، المرفوعات من الآجرومية).

### 6. 🗂️ مستعرض المسائل وإدارة البطاقات
- محرك بحث عربي فوري يتجاهل التشكيل والهمزات.
- تصفية حسب العلم أو الرزمة أو حسب الحالة (المستحقة اليوم، قيد التعلم، المتقنة).
- إمكانية إضافة مسألة جديدة أو تعديل أي مسألة.
- **تصدير واستيراد رزم المسائل (JSON & .apkg)** لمشاركتها مع الإخوة وطلاب العلم.

## ⚡ التشغيل والتجربة

### 1. تشغيل التطبيق في بيئة التطوير
```bash
cd /teamspace/studios/this_studio/zad-ilm/src-tauri
cargo run
```

### 2. بناء ملف تنفيذي للينكس (Linux Binary)
```bash
cd /teamspace/studios/this_studio/zad-ilm/src-tauri
cargo build --release
```
الملف التنفيذي الناتج سيكون في: `target/release/zad-al-ilm` بحجم بضعة ميجابايتات وسرعة فائقة.

### 3. بناء نسخة ويندوز (Windows .exe)
راجع الدليل المفصل في ملف: [`BUILD_WINDOWS_EXE.md`](file:///teamspace/studios/this_studio/zad-ilm/BUILD_WINDOWS_EXE.md).
